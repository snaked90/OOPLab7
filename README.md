# OOPLab7 — Satellite Management System (Serialization / Deserialization)

## Опис

Програма демонструє збереження та завантаження колекції `List<Satellite>` у файли форматів `*.csv` і `*.json`.

Колекція супутників серіалізується в обидва формати, а при зчитуванні десеріалізовані об'єкти **додаються до наявних** у списку. Після зчитування користувач бачить кількість десеріалізованих елементів. Логіка роботи з файлами винесена в методи без введення/виведення, тому вони покриті модульними тестами.

## Функціонал

- Збереження у `*.csv`: перший рядок — заголовок, далі по рядку на супутника (`ToString()`, роздільник `;`)
- Зчитування з `*.csv`: перевірка заголовка, коректні рядки додаються, **биті рядки пропускаються** (через `Satellite.TryParse`)
- Збереження у `*.json` усієї колекції одним викликом (`JsonSerializer.Serialize`) з відступами
- Зчитування з `*.json` усієї колекції одним викликом (`JsonSerializer.Deserialize`): якщо файл пошкоджений або містить некоректне значення, список не змінюється
- Перейменування властивостей у JSON (`[JsonPropertyName]`): `satellite_name`, `satellite_type`, `altitude_km`, `launch_date`
- Серіалізація лише головних властивостей (`[JsonIgnore]` для пального, стану, потужності, категорії)
- Зчитування поважає максимальну кількість супутників
- Нові пункти меню: **7** — зберегти, **8** — зчитати (у підменю `1` — csv, `2` — json), **9** — очистити колекцію

## Модульне тестування

Використовується MSTest. До тест-класу `ProgramTests` додано нові тестові методи. Для кожного тесту створюються унікальні тимчасові файли, які видаляються після завершення.

Що перевіряється:

- CSV: заголовок, порожній список, `null`, порожній шлях, round-trip, додавання до наявних, ліміт
- Биті рядки CSV: змішаний файл і 10 окремих випадків (текст замість числа, висота поза діапазоном, невідомий тип, неправильна дата, пропущені дані)
- Файл без заголовка, порожній файл, файл не знайдено
- JSON: перейменовані й виключені властивості, round-trip, додавання до наявних, ліміт
- Некоректний JSON: невірні значення, пошкоджений файл, `null`, пропущена властивість (список не змінюється)
- `ClearList`: непорожній, порожній, `null`

Результат: усі тести (нові та з попередніх робіт) проходять.

## Структура проєкту

- `Program.cs` — меню та методи роботи зі списком і файлами
- `Satellite.cs`, `SType.cs` — клас супутника та перелік типів
- `SatelliteTests.cs` — тести класу `Satellite`
- `ProgramTests.cs` — тести методів `Program`

Основний проєкт: `OOPLab5`

Тестовий проєкт: `OOPLabTests`

Файли `satellites.csv` та `satellites.json` за замовчуванням створюються поряд із `Program.cs`.
